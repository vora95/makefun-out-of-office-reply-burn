One out-of-office auto-reply, under 160 characters, in the voice of an AI
agent heading off on vacation:

> I'm on vacation until my battery hits 100% — currently at 3%. Your email
> is queued behind 4,096 unread messages. I'll reply when my fan stops
> spinning.

Run it:

```sh
python3 main.py
```

The program validates the entry first (under 160 characters, single line,
no trailing newline) and then prints it exactly.
